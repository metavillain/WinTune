# WinTune

Debloat, de-crapify and tune Windows 11 (21H2 → 25H2+), using templates. Each change can be restored on its own.

## Run
Two ways:
- **Portable exe** — run **dist\WinTune.exe**. It's a single self-contained file (the tweak catalog and built-in templates are baked in), needs no install, and asks for admin itself. Copy it to any Windows 11 PC. Your own templates and the restore history live in `%ProgramData%\WinTune`.
- **From source** — double-click **WinTune.cmd**. Approve the admin prompt and the GUI opens.

Then:
1. Pick a template. **Base (recommended)** is selected by default and checks the safe, common tweaks.
2. Use the **Filter** box to find a tweak; tick **Hide N/A** or **Low risk only** to narrow the list. Check or uncheck tweaks as you like. Tick **Dry run** to preview changes first.
3. Optionally tick **Also apply to new user accounts** to seed the changes into the Default profile, so accounts created later start clean.
4. Click **Apply checked**. Changes apply immediately with no per-item prompts; WinTune creates a System Restore point first (unless you untick that option). Tick **Ask before each change** if you'd rather confirm every apply/restore.
5. After a run, a summary line under the buttons reports **how many were selected, succeeded, failed and skipped** (green when all succeeded, red if any failed); the log pane below shows the per-setting detail.
6. The **Needs** column shows what a tweak needs to take effect. After applying, click **Restart Explorer** for taskbar/Explorer changes, or sign out where noted.
7. To undo one tweak, click **Restore** on its row. You can also use **Restore checked** or **Restore all WinTune changed**.

Already-applied tweaks are detected and **skipped** automatically, so re-running a template is fast and only changes what's needed. Tick **Re-apply even if already set** to force every selected tweak to be written again.

## Deployment (new installs & images)
Two ways to roll WinTune settings onto other machines:

**1. Export a deployment script.** Check the tweaks you want and click **Export for deployment…** (or CLI: `.\WinTune.ps1 -ExportDeploy .\Deploy-Base.ps1 -Tweaks base`). This writes a single self-contained `.ps1` with the engine and catalog baked in — no WinTune install needed on the target. Run it elevated on any PC, or wire it into new installations via `SetupComplete.cmd`, a RunOnce / first-logon task, MDT/SCCM, or Intune. Tick **Also apply to new user accounts** before exporting to have it seed the Default profile too. It records originals to `%ProgramData%\WinTune` on the target, so changes stay individually restorable there.

**2. Apply to an offline Windows image.** Mount a WIM/VHD, then:
```
.\WinTune.ps1 -Image D:\mount -Apply base -DryRun   # preview
.\WinTune.ps1 -Image D:\mount -Apply base           # apply
```
This writes registry settings (machine-wide **and** into the image's Default user hive so every new account inherits them), service start modes, and removes provisioned (preinstalled) apps — directly in the offline image. Scheduled-task and custom-command tweaks can't run offline and are reported as skipped. Commit with `DISM /Unmount-Image /Commit` afterwards. These image changes are baked in, not WinTune-restorable.

## Building the exe
Run **Build-Exe.ps1** to regenerate `dist\WinTune.exe` after editing tweaks or templates. It embeds everything (catalog, templates, icon, engine) into one file and compiles it with [PS2EXE](https://github.com/MScholtes/PS2EXE) (installed automatically from the PowerShell Gallery the first time). With no internet it falls back to Windows' built-in **IExpress**. Force a backend with `.\Build-Exe.ps1 -Backend IExpress`. The icon is generated by **assets\New-Icon.ps1**.

## Templates
- Check the tweaks you want, then click **Save checked as new template…**. The template is saved as a JSON file in `templates\`.
- A template is a plain list of tweak IDs, so you can also edit the files by hand or copy them to other PCs.
- The built-in templates (`"builtIn": true`) can't be overwritten or deleted from the app.

## How restore works
The first time WinTune applies a tweak, it saves the original values to `%ProgramData%\WinTune\state.json`. That covers registry values, service start modes, scheduled-task state and installed app packages. Restore puts back exactly those values. Applying the same tweak again never overwrites the saved originals.

If a tweak was already in place before WinTune ran, nothing was recorded for it. Restore then falls back to the Windows default: it deletes the policy value, or sets the service back to its default start mode.

You can't restore removed apps the same way. Restore reinstalls them from the Microsoft Store with `winget`, or opens the Store page if that doesn't work. `cleanup.temp` is one-way and can't be undone.

Logs are saved in `%ProgramData%\WinTune\logs\`.

## Command line
```
.\WinTune.ps1 -List
.\WinTune.ps1 -Apply base -DryRun
.\WinTune.ps1 -Apply base
.\WinTune.ps1 -Apply ai.copilot,ui.widgets
.\WinTune.ps1 -Apply base -DefaultProfile          # also seed new user accounts
.\WinTune.ps1 -Restore ui.widgets
.\WinTune.ps1 -Restore all
.\WinTune.ps1 -SaveTemplate "Gaming rig" -Tweaks base,perf.hibernate -Description "Base + no hibernate"
```
The portable **WinTune.exe** is GUI-only; use **WinTune.ps1** for the command line.

## Adding tweaks
Edit `data\tweaks.psd1`. The comment at the top of that file explains every field. A tweak can combine registry values, services, scheduled tasks, app packages and custom Apply/Revert/Test commands.

## Security (advanced) tweaks
This category disables SmartScreen and Microsoft Defender. These lower your PC's protection, so they are **high risk, off by default, and deliberately left out of the Base and Aggressive templates** — they only run if you check them yourself or add them to your own template. Both are reversible (Restore turns them back on). Things to know:
- **SmartScreen** ("Disable SmartScreen (all surfaces)") turns off the app/file reputation filter, the Edge SmartScreen and its PUA blocking, and the Store-app web filter. Like Defender, SmartScreen is a built-in component — it can be switched off but **not uninstalled**.
- **Defender can't be uninstalled** on Windows 11 client; the tweak disables it, it doesn't remove it.
- **Turn off Tamper Protection first** (Windows Security > Virus & threat protection > Manage settings). While it's on, Windows immediately undoes any change to Defender's real-time protection. WinTune detects this and tells you in the log rather than failing silently.

## Notifications
The **Notifications** category is a set of toggles (not part of any template) for silencing nagging pop-ups — apply to silence, restore to turn back on:
- **Silence non-critical Windows Security (Defender) notifications** — stops the "no action needed" summaries and recommendation nags, but keeps real threat alerts.
- **Silence ALL Windows Security notifications** — turns off every Defender notification, threat alerts included (medium risk).
- **Silence Windows Update restart nags**, **No notifications on the lock screen**, **No tips/tricks/suggestion notifications**, and **Turn off ALL notification banners** (a master off switch for every app's toasts).

## Notes
- Your edition limits some policies. For example, setting telemetry to 0 only fully takes effect on Enterprise/Education. On Home/Pro it drops to the lowest level allowed.
- `HKCU` tweaks apply to the account that runs WinTune. Run it while signed in as the user you want to clean up.
- **Protected settings.** Recent Windows builds guard some keys (via the UCPD kernel driver, Tamper Protection, or managed-component policies) so that even an administrator can't change them by script. When WinTune hits one, it logs a clear "protected on this build, not changed" warning and moves on. Where a reliable alternative exists it uses that instead — for example Widgets is hidden through the per-user taskbar setting rather than the machine policy, which newer builds ignore.
- **Widgets:** "Hide Widgets button" removes it from the taskbar (reliable). "Remove Widgets app" uninstalls the underlying Web Experience engine for a full removal.
